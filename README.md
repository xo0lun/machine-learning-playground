A practical collection of Machine Learning algorithms, data preprocessing techniques, and model evaluation examples implemented in Python.

## Overview

This repository was created as a hands-on reference for studying and experimenting with classical Machine Learning techniques using real datasets and reproducible workflows.

The project focuses on:

- Data preprocessing
- Supervised learning
- Unsupervised learning
- Model evaluation
- Data visualization
- Reproducible experiments

## Features

- Clean project structure
- Well-documented Python code
- Jupyter notebooks
- Reusable utility functions
- Multiple datasets
- Visualization examples

## Algorithms

- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Naive Bayes
- K-Means Clustering
- Principal Component Analysis (PCA)

## Technologies

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Plotly
- Jupyter Notebook
